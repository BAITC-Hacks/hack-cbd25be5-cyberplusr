# Демонстрация за пять минут

До выступления: запустить run.py, затем audit_model.py; открыть интерфейс и локальный public/results/CASE_REVIEW.md. Выбрать из этого файла по одному gid для консолидации, распределения, координации и границы depth=4. Использовать полные идентификаторы без округления Excel.

| Время | Действие | Что сказать |
|---|---|---|
| 0:00–0:40 | Показать главный экран и архитектуру | Аналитик начинает с нижнего уровня. Мы собираем наблюдаемые связи в граф и объясняем, кого проверять первым. |
| 0:40–1:30 | Найти пример consolidator | Несколько плательщиков сходятся в один узел; показать долю наблюдаемого выхода, входящие стрелки и объяснение. Это гипотеза консолидации. |
| 1:30–2:20 | Найти distributor, включить всех соседей и fit view | Видно веерное распределение. Для чтения вернуть 16 соседей. Большое превышение выхода над входом объясняется неполной выборкой и само по себе не доказывает нарушение. |
| 2:20–3:10 | Открыть первого кандидата из очереди | Показать посредничество, достижимость от seed и вклад признаков в оценку. Пояснить разницу между силой подтверждения роли и приоритетом проверки. |
| 3:10–3:50 | Открыть узел depth=4, затем изолированный seed | Обрыв данных нельзя выдавать за конечного бенефициара; seed без связей тоже сохранены. |
| 3:50–4:25 | Переключить цвет по кластерам, фильтр, затем сброс | Кластеры группируют наблюдаемую структуру; сами по себе они не доказывают общую преступную деятельность. |
| 4:25–5:00 | Показать CSV, методику и VALIDATION.md | Расчёт воспроизводим. Устойчивость проверена изменением порогов и весов, но точность ролей без разметки неизвестна. Следующий шаг — экспертная проверка. |

Если спросят про AI: текущий прототип использует графовые алгоритмы и объяснимые правила, а не обученную нейросеть. Не заявлять метрики accuracy/F1 без размеченного эталона.

Если нет доступа к исходным данным: чистый клон показывает синтетический пример с явной пометкой. Это демонстрация интерфейса, а не результаты реального набора.
