## Чувствительность

Базовые роли: coordinator 27, distributor 40, consolidator 87, transit 69, terminal 1 034, peripheral 991. terminal в UI назван «Получатель в выборке».

Согласованное ужесточение порогов изменяет 89 назначений (3,96%), смягчение — 180 (8,01%). Точные наборы порогов заданы в audit_model.py и сохраняются в model_audit.json. Это два сценария, не доверительный интервал.

При независимом изменении каждого веса приоритета на ±20% с нормировкой в топ-20 остаются 18–20 исходных узлов. Устойчивость состава списка не доказывает правильность его участников.

Louvain, seeds 7/21/42/84/123: 92/87/91/90/92 кластера. Adjusted Rand Index относительно базового разбиения: 0,9118 / 0,8676 / 1 / 0,8628 / 0,8998. При повторении seed=42 разбиение совпало. При смене seed некоторые границы сообществ меняются.

## Экспертная проверка

Результат audit_model.py включает CASE_REVIEW.md с тремя примерами каждой роли. Аналитик должен проверить первичные связи, альтернативные объяснения и ограничения каждого примера. Без размеченных ролей нельзя сообщать accuracy, precision, recall или F1. Сила подтверждения роли не калибрована как вероятность.
